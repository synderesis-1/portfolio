# Portfólio Pessoal - Fernanda Brunelli

## Nome do Aluno
Fernanda Brunelli

## Descrição do Portfólio
Portfólio profissional e acadêmico desenvolvido com layout Bento-grid minimalista, estruturado em Bootstrap 5, refletindo competências em Defesa Cibernética e Desenvolvimento de Sistemas.

## Tecnologias Utilizadas
- HTML5 & CSS3
- Bootstrap 5 & Bootstrap Icons
- GitHub Pages

## Link do Site Publicado
https://synderesis-1.github.io/portifolio/

## Explicação do Funcionamento do Projeto
O site utiliza uma estrutura modular dividida em seções (Perfil, Habilidades, Projetos e Contato) com navegação fluida por âncoras e cartões de redirecionamento direto com identidades visuais em gradiente.

## Descrição do Recurso Novo Adicionado
Inclusão de uma seção dedicada de Habilidades & Formação com abas interativas do Bootstrap (`nav-pills`) e cartões de projetos do TryHackMe e GitHub com proporções, escalas e avatar aprimorados.

## Como o Recurso foi Implementado
Utilizando componentes nativos do Bootstrap 5 (`nav-pills` e grid responsivo) com estilização CSS personalizada para gradientes refinados e interatividade fluida.
