# Portfólio Pessoal - Fernanda Brunelli

## Nome do Aluno
Fernanda Brunelli

## Descrição do Portfólio
Portfólio profissional e acadêmico desenvolvido com layout Bento-grid minimalista, estruturado em Bootstrap 5, refletindo competências em Defesa Cibernética e Desenvolvimento de Sistemas.

## Tecnologias Utilizadas
- HTML5 & CSS3
- Bootstrap 5 & Bootstrap Icons
- JavaScript (Modais e Interatividade)
- GitHub Pages

## Link do Site Publicado
https://synderesis-1.github.io/portifolio/

## Explicação do Funcionamento do Projeto
O site utiliza uma estrutura modular dividida em seções (Perfil, Habilidades, Projetos e Contato) com navegação fluida por âncoras e cartões interativos em formato modal.

## Descrição do Recurso Novo Adicionado
Inclusão de uma seção dedicada de Habilidades & Formação com abas interativas do Bootstrap (`nav-pills`) e modais informativos dinâmicos em cada cartão de projeto.

## Como o Recurso foi Implementado
Utilizando componentes nativos do Bootstrap 5 (`nav-pills` para alternância de conteúdo e `modal` para exibição detalhada dos projetos), estilizados com temas escuros consistentes.
